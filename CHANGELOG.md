# Changelog

## 0.1.0 — 2026-11-06

First public research preview. Earlier internal prototype numbering is not a
published semantic-version history.

- Two-way terminal chat and loopback-only simulator server.
- Cirq/qsimcirq superdense coding with explicit A-qubit transfer.
- UTF-8 frames, SHA-256 checksums, classical ACK/NACK, bounded retry and deduplication.
- Observer viewer with amplitudes, exact noisy density matrices and actual shot histograms.
- Three executable scientific notebooks, diagrams, derivations and primary references.
- MIT license, portable installation, package metadata, console commands and CI.

This release is a local simulation and educational research preview. It does
not implement physical quantum networking, encryption, authentication, QML,
or communication using entanglement alone. Acknowledgement and quantum-transfer
resource counts are model costs; simulator TCP traffic is classical and separate.
